# Crossword Puzzle - 英语填词游戏

一个纯前端的英语填词游戏，支持四个难度等级，无需安装，浏览器直接打开即可游玩。

**[在线试玩](https://ianivan743-rgb.github.io/crossword-puzzle-game/)**

## 游戏特色

- **四个难度等级**
  - 简单：3-4 字母单词，中文提示
  - 中等：4-5 字母单词，中文提示
  - 困难：5-7 字母单词，英文提示
  - 地狱：7-10 字母单词，英文提示
- **自动跳转**：输入字母后自动跳到下一格，填完一个词自动跳到下一个未完成的词
- **智能辅助**：Check 检查答案、Hint 提示、Confirm 确认提交
- **计时系统**：记录完成用时，胜利时展示成绩
- **随机生成**：每次游戏随机生成新谜题，可反复游玩
- **双列题目布局**：提示分两列展示，无需滚动；地狱难度自动切换为单列宽布局

## 操作方式

| 操作 | 说明 |
|------|------|
| 点击格子 | 选中并开始填词 |
| 输入字母 | 填入当前格并自动跳转下一格 |
| 退格键 | 删除当前字母并回退 |
| 方向键 | 移动光标 |
| Tab | 切换横向 / 纵向方向 |
| 点击同一格子 | 在横向和纵向之间切换方向 |

## 技术说明

- 单文件 HTML，零依赖，双击即可运行
-  crossword 网格由算法自动生成（贪心放置 + 多次随机取最优）
- 纯原生 JavaScript，无框架依赖
- 响应式布局，支持桌面和移动端

## 本地运行

直接双击 `index.html` 文件，用任意浏览器打开即可。
